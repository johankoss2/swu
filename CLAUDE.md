# Holotable (swu)

## Versioning
- The app version is shown in the header of `index.html` (`HOLOTABLE · COLLECTION LOG … vX.Y`).
- Bump the minor version (e.g. v1.1 → v1.2) with each change to the app.
- Only bump once per release: if the version has already been bumped and those changes
  haven't been deployed yet, include new changes under that same version.
